# ♻️ EcoTrack – Smart Waste Management System

EcoTrack is a full-stack Smart Waste Management platform designed to streamline waste collection through real-time monitoring, intelligent route optimization, and role-based management for citizens, workers, and administrators.

## 📋 Features

- 🔐 Secure Authentication for Users, Workers, and Administrators
- 🗑️ Waste Pickup Request System with Image Uploads
- 📍 GPS-based Pickup Location Tracking
- 🚛 Intelligent Route Optimization for Collection Workers
- 📊 Admin Dashboard with Analytics and Waste Statistics
- 👷 Worker Dashboard for Task Assignment and Management
- 🔄 Real-time Pickup Status Updates using WebSockets
- 🗺️ Interactive Map for Monitoring Waste Collection Activities

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or above)
- MongoDB
- Cloudinary Account (Image Storage)

---

### Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Riya12-4/EcoTrack.git
cd EcoTrack
```

### 2. Install Backend Dependencies

```bash
cd backend
npm install
```

### 3. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the `backend` folder and configure:

- MongoDB URI
- JWT Secret
- Cloudinary Credentials

### 5. Start Backend

```bash
cd backend
npm start
```

### 6. Start Frontend

```bash
cd frontend
npm run dev
```
